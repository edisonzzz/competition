## 修正后的正确架构

### 团队结构
```
团队 Alpha
├─ 成员1 (alpha_m1) - 个人账号
├─ 成员2 (alpha_m2) - 个人账号
├─ 成员3 (alpha_m3) - 个人账号
├─ 成员4 (alpha_m4) - 个人账号
└─ 成员5 (alpha_m5) - 个人账号

❌ 没有团队协作账号！
✅ Phase 3时，5个人用各自账号登录，看到同一个IR场景，任何人提交都算
```

### 题库分配逻辑
```
团队题库（共享池）
├─ 题目A (未分配)
├─ 题目B (分配给成员1，倒计时2:30)
├─ 题目C (已被成员2答对，整个团队标记已解决)
├─ 题目D (被成员3跳过，返回池中)
└─ 题目E (未分配)

规则：
1. 每个成员同时只能看1道题
2. 3分钟倒计时，到期自动返回题库
3. 答对后，整个团队该题标记已解决，不再分配给任何成员
4. 跳过后返回题库，其他成员可抽到
5. 每人最多跳过3次
```

### 计分逻辑
```
Phase 1 (MC):
- 成员1: 100 + 150 + 200 = 450分
- 成员2: 100 + 150 = 250分
- 成员3: 100 + 100 + 100 = 300分
- 成员4: 150 + 200 = 350分
- 成员5: 100 + 150 + 150 = 400分
Phase 1 团队总分: 1750分

Phase 2 (技术):
- 成员1: 250 + 300 = 550分
- 成员2: 250 + 250 = 500分
- 成员3: 400 = 400分
- 成员4: 250 + 300 + 400 = 950分
- 成员5: 250 + 250 = 500分
Phase 2 团队总分: 2900分

Phase 3 (IR):
- 5个成员协作解决同一个IR
- IR总分: 5000分（5个步骤，每步1000分）
- 任何成员提交都算团队分数
Phase 3 团队总分: 5000分

最终团队总分: 1750 + 2900 + 5000 = 9650分
```
