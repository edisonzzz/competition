cat << 'EOF'

📦 Deployment Steps:

1️⃣ Upload project to server
   Run locally:
   scp -r blueteamctf-cn root@116.62.236.60:/root/

2️⃣ Connect to server
   ssh root@116.62.236.60

3️⃣ Enter project directory
   cd /root/blueteamctf-cn

4️⃣ Run deployment script
   chmod +x deploy-cn.sh
   ./deploy-cn.sh

5️⃣ Access the system
   http://116.62.236.60:5173

🔧 Manual Deployment (if script fails):

# 1. Install Docker
curl -fsSL https://get.docker.com | bash -s docker --mirror Aliyun
systemctl start docker
systemctl enable docker

# 2. Install Docker Compose
curl -L "https://get.daocloud.io/docker/compose/releases/download/v2.20.0/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
chmod +x /usr/local/bin/docker-compose

# 3. Configure Docker mirror acceleration
mkdir -p /etc/docker
cat > /etc/docker/daemon.json <<JSON
{
  "registry-mirrors": [
    "https://docker.mirrors.ustc.edu.cn",
    "https://hub-mirror.c.163.com"
  ]
}
JSON
systemctl restart docker

# 4. Start services
cd /root/blueteamctf-cn
docker compose up -d --build

# 5. Check logs
docker compose logs -f

---

🛠️ Common Commands:

# Check service status
docker compose ps

# Check logs
docker compose logs -f

# Restart services
docker compose restart

# Stop services
docker compose down

# Full cleanup and restart
docker compose down -v
docker system prune -af
docker compose up -d --build

---

🔥 Firewall Configuration:

# Open ports (if using firewall)
firewall-cmd --permanent --add-port=5173/tcp
firewall-cmd --permanent --add-port=3001/tcp
firewall-cmd --reload

# Or using iptables
iptables -A INPUT -p tcp --dport 5173 -j ACCEPT
iptables -A INPUT -p tcp --dport 3001 -j ACCEPT

---

⚠️ Troubleshooting:

1. If frontend cannot be accessed:
   - Check firewall: systemctl status firewalld
   - Check port: netstat -tlnp | grep 5173

2. If Docker build is slow:
   - Verify mirror acceleration is configured
   - Check /etc/docker/daemon.json

3. If containers cannot start:
   - Check logs: docker compose logs
   - Check port usage: lsof -i :5173

EOF
