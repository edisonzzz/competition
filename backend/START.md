# 🚀 启动蓝队CTF平台

## 快速启动（3步）

### 1️⃣ 打开第一个终端 - 启动后端
```bash
cd backend
npm run dev
```
看到 "🛡️ 蓝队CTF平台后端启动成功" 即可

### 2️⃣ 打开第二个终端 - 启动前端
```bash
cd frontend  
npm run dev
```
看到 "Local: http://localhost:5173/" 即可

### 3️⃣ 打开浏览器
访问: http://localhost:5173
